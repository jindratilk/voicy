## Clean-host failure and verified cause — 17 October afternoon

[Run 39045468738](https://github.com/jindratilk/voicy/actions/runs/39045468738), source `25e4a6063fa0799fb74cb3157645d92e70c096a6`, tested the exact final DMG on a new macOS 15.7.9 arm64 VM. DMG/app signatures, tickets, Gatekeeper and image checksum passed. The actual native app launched its bundled authenticated local engine, exposed the installed AuK runtime, and analyzed the licensed 4.905-second input. AuK then failed before model inference: `Failed to load the default metallib ... language version 4.0 ... not supported on this device`. No enhanced export or complete native GUI/public-download pass is claimed.

Read-only inspection of all 25 installed platform-wheel metadata identifies `mlx-0.32.2` and `mlx_metal-0.32.2` as `macosx_26_0_arm64`; all other platform wheels declare a baseline no newer than 14. [Official MLX](https://pypi.org/project/mlx/0.32.2/#files) and [MLX Metal](https://pypi.org/project/mlx-metal/0.32.2/#files) provide the same versions for macOS 14, 15 and 26. A version-only lock on a macOS 26 build host selected incompatible artifacts. Pin both baseline-14 wheel artifacts and audit staged platform tags. Then test actual Metal computation on clean macOS 14/15 and the complete rebuilt candidate before release. The virtual GPU and 7 GiB RAM are additional limitations; correcting wheel metadata alone does not establish full model compatibility.

The merged staging correction in [PR #7](https://github.com/jindratilk/voicy/pull/7) pins both official baseline-14 wheel hashes and rejects newer installed platform tags. [Actual clean-host GPU checks](https://github.com/jindratilk/voicy/actions/runs/39046603975) pass on macOS 14.8.9 and 15.7.9; a new isolated developer environment on macOS 27.0.1 also passes. These prove the corrected pair imports and computes on the tested OSes. They do not turn the existing frozen DMG into a corrected artifact or establish complete AuK/model/native-flow compatibility.

Merged source: `0e151e7806ada7a1ab793c4d9207e25194208f6d`, tree-identical to final reviewed/tested head `8e4858141cc829e847da5accc37d79931724cd42`. Both new regression tests are included in backend CI. All frontend/backend/website checks and clean macOS 14/15 GPU jobs passed before merge. No installer was rebuilt or publicly released by this source merge.
