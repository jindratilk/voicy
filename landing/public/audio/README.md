# Website demonstration

Original text: “Enhance your speech with Voicy. For free. Fully on your Mac. Turn noisy recordings into clear speech, without sending your audio to the cloud.”

Clean voice: ElevenLabs, George, eleven_multilingual_v2. A generated sample; not a recording of the developer or a user. The before sample adds deterministic simulated fan noise (overall SNR 9 dB), mild band limiting and two room reflections. The after sample is actual Voicy AuK32 output: q8/group64, 32 steps, seed2026, CFG2. Both are mastered using the app's two-pass loudness normalization. Length: approximately8.684 seconds. The clean reference is not substituted for the enhanced sample. Transcription of both clean and enhanced versions matched in an independent local Whisper check; that is not a universal audio-quality guarantee.

These recordings are demonstration assets distributed with the project. ElevenLabs-generated audio is not model code or a claim of human endorsement.
